# YUMY Ocean 0.4.3

This update fixes the visual issues shown in the user's screenshots:

- Clean transparent lionfish sprite replaces the old image with a visible matte/background.

Web source is in `www/`. Android wrapper setup remains Capacitor-based; this ZIP is source, not a compiled APK.
