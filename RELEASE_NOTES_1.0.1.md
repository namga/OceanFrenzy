# YUMY Ocean 1.0.1 – Launch & Controls Hotfix

- Fixed missing explicit runtime state in the strict-mode game script that prevented startup/gameplay initialization.
- Desktop: mouse movement alone steers the fish; no click or hold is required.
- Desktop: holding the left mouse button activates a 1.5× swim-speed boost for 5 seconds.
- Boost cooldown is 180 seconds after the 5-second boost finishes.
- Android remains touch-and-drag; mouse boost is desktop-only.
- Updated PWA cache to yumy-ocean-1.0.1.
